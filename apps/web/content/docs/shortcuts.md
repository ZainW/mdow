# Keyboard Shortcuts

Mdow is built for keyboard-first reading. Press **⌘/** (macOS) or **Ctrl+/** (Linux) for the full list of shortcuts.

![The Mdow command palette listing files in an open folder](/screenshots/palette-light.webp)

## Files

| Action      | macOS | Linux        |
| ----------- | ----- | ------------ |
| Open file   | ⌘O    | Ctrl+O       |
| Open folder | ⌘⇧O   | Ctrl+Shift+O |

## Navigation

| Action             | macOS | Linux          |
| ------------------ | ----- | -------------- |
| Command palette    | ⌘K    | Ctrl+K         |
| Find in document   | ⌘F    | Ctrl+F         |
| Switch tab by slot | ⌘1–9  | Ctrl+1–9       |
| Close tab          | ⌘W    | Ctrl+W         |
| Next tab           | ⇧⌘]   | Ctrl+Tab       |
| Previous tab       | ⇧⌘[   | Ctrl+Shift+Tab |
| Back, forward      | ⌘[ ⌘] | Alt+← Alt+→    |

## View

| Action             | macOS | Linux              |
| ------------------ | ----- | ------------------ |
| Toggle sidebar     | ⌃⌘S   | Ctrl+B             |
| Split view         | ⌘\\   | Ctrl+\\            |
| Keyboard shortcuts | ⌘/    | Ctrl+/             |
| Zoom in            | ⌘+    | Ctrl++             |
| Zoom out           | ⌘-    | Ctrl+-             |
| Reset zoom         | ⌘0    | Ctrl+0             |
| Toggle full screen | ⌃⌘F   | your desktop's own |

## App

| Action   | macOS | Linux  |
| -------- | ----- | ------ |
| Settings | ⌘,    | Ctrl+, |

## Command palette actions

Some view actions do not need dedicated global shortcuts. Press `Cmd+K` or `Ctrl+K` to run actions such as opening a file, opening a folder, toggling split view, switching between light and dark, opening settings, and showing keyboard shortcuts.
