# Getting Started

Mdow is a native markdown reader for macOS and Linux. Open Markdown or local HTML files in a focused desktop app, then ask about your documents with Claude Code, Codex, Cursor or OpenCode.

## Quick start

1. [Download Mdow](/download) for your platform
2. Install and launch the app
3. Open a Markdown or HTML file, open a folder, or drag documents into the window

> **Note:** Mdow is a viewer, not an editor. Pair it with your favorite text editor for the best workflow.

## AI companion

Open the companion to ask about the focused document or an open folder. Add specific files and folders with `@` tags when you want tighter context. Mdow runs the agent you choose, Claude Code, Codex, Cursor or OpenCode, and its answers include clickable source citations.

The companion never changes a document without your OK: suggested edits come back as diffs to accept or decline. See the [AI companion guide](/docs/ai-companion) for provider and context details.

## Supported formats

- `.md` — standard Markdown
- `.markdown` — alternative extension
- `.mdx` — MDX files (rendered as Markdown)
- `.html` / `.htm` — local HTML previews in a sandboxed viewer

## Command palette

Press `Cmd+K` (or `Ctrl+K`) to search open-folder files and run common actions such as opening a file, opening a folder, toggling the sidebar, switching wide mode, toggling split view, opening settings, or showing keyboard shortcuts.

## Keyboard shortcuts

| Action           | macOS   | Linux    |
| ---------------- | ------- | -------- |
| Command palette  | `Cmd+K` | `Ctrl+K` |
| Find in document | `Cmd+F` | `Ctrl+F` |
| Toggle sidebar   | `Cmd+B` | `Ctrl+B` |
| Settings         | `Cmd+,` | `Ctrl+,` |
| Close tab        | `Cmd+W` | `Ctrl+W` |

Press `Cmd+/` (or `Ctrl+/`) inside the app to see the full shortcuts list, or read the [keyboard shortcuts guide](/docs/shortcuts).
